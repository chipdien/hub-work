Plugin mở rộng UI theo cách nào?

Chọn mô hình phù hợp nhất — ảnh hưởng đến cách developer viết plugin.

A

📄 Page-only — Plugin = Trang mới

Plugin chỉ thêm được route/page mới vào sidebar. Đơn giản, dễ kiểm soát.

Shell App
🏠 Dashboard
─────────
📦 CRM ← plugin
📚 LMS ← plugin
📋 Tasks ← plugin
Plugin page rendered here

Plugin không can thiệp được vào ngoài page của mình
B

🧩 Slot-based — Plugin inject vào slots

Shell app định nghĩa các "slot" (vị trí). Plugin đăng ký component vào slot đó. Linh hoạt hơn nhiều.

Shell App — Dashboard
slot: "dashboard.top"
← CRM plugin: Revenue Widget
slot: "dashboard.top"
← LMS plugin: Course Widget
slot: "dashboard.bottom" ← Tasks plugin: My Tasks
C

⚡ Full Extension — Pages + Slots + Hooks

Plugin có thể: thêm trang, inject vào slots, đăng ký sidebar items, thêm menu actions, listen/emit events. Mạnh nhất — như VS Code extension model.

Shell App — Plugin API
plugin.registerPage('/crm', CRMPage)
plugin.registerSlot('dashboard.top', RevenueWidget)
plugin.addSidebarItem({ label: 'CRM', icon: '👥' })
plugin.onEvent('user.created', handler)
plugin.addContextMenu('contact', actions)
