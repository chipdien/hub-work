Plugin hoạt động theo cơ chế nào?

Đây là quyết định kiến trúc quan trọng nhất — ảnh hưởng đến toàn bộ hệ thống.

A

📦 Module-based (Static)

Plugin được cài vào hệ thống lúc deploy (npm package, git submodule). Cần restart để kích hoạt. Đơn giản, ổn định, dễ kiểm soát. Như Odoo modules, Django apps.

Pros

  • Dễ implement
  • Hiệu năng tốt
  • Type-safe

Cons

  • Cần redeploy
  • Không hot-reload
B

⚡ Dynamic (Runtime)

Plugin được bật/tắt trong lúc app đang chạy — không cần restart. Admin vào UI cài và dùng ngay. Như WordPress plugins, VS Code extensions.

Pros

  • Linh hoạt
  • UX tốt hơn
  • Multi-tenant friendly

Cons

  • Phức tạp hơn
  • Cần sandbox/isolation
C

🔌 Micro-frontend / Federated

Mỗi plugin là một micro-app độc lập (React/Vue app riêng), được load vào shell app qua Module Federation. Như Backstage plugins.

Pros

  • Team độc lập
  • Deploy riêng
  • Tech stack tự do

Cons

  • Infrastructure phức tạp
  • Bundle size lớn
